# Controller System Summary 

We built a dual input control system for a shooter game using a modified Nerf gun and a DDR style movement pad. The Nerf gun was taken apart and upgraded with sensors so that moving the gun directly controls the mouse cursor for aiming. It includes trigger buttons for shooting and aiming, along with extra buttons mapped to game specific actions.

Movement is handled through a DDR style pad where stepping on different panels determines the player’s direction. Since all inputs are mapped to standard mouse and keyboard controls, the system can be used with any game or even general computer applications by remapping the buttons as needed.

# Download game

This controller system was designed to be used with The Last Run Project Hope, a third person zombie parkour shooter developed by the UB Fall 2024 CSE 410 Game Development team.
